### `01` &nbsp; System Architecture & Specifications

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>⚡ High-Concurrency API Layer</h4>
      <p>
        <sub><b>Python & FastAPI</b> merkezli asenkron servis mimarisi. Binlerce eşzamanlı isteği bloklamadan karşılayan (non-blocking I/O), JWT kimlik doğrulama, WebSocket gerçek zamanlı veri akışı ve katmanlı güvenlik kurallarıyla donatılmış çekirdek API altyapısı.</sub>
      </p>
      <p>
        <img src="https://img.shields.io/badge/Python-141419?style=flat-square&logo=python&logoColor=ffd60a" />
        <img src="https://img.shields.io/badge/FastAPI-141419?style=flat-square&logo=fastapi&logoColor=00d0b4" />
      </p>
    </td>
    <td width="50%" valign="top">
      <h4>🧠 In-Memory & Relational Data Engine</h4>
      <p>
        <sub><b>Redis & SQL</b> ile hibrit veri yönetimi. Milisaniyelik tepki süreleri için dağıtık önbellekleme (distributed caching), akıllı istek sınırlandırma (rate-limiting), Pub/Sub mesaj kuyrukları ve ACID uyumlu ilişkisel veritabanı optimizasyonu.</sub>
      </p>
      <p>
        <img src="https://img.shields.io/badge/Redis-141419?style=flat-square&logo=redis&logoColor=ff453a" />
        <img src="https://img.shields.io/badge/PostgreSQL_/_MySQL-141419?style=flat-square&logo=postgresql&logoColor=2997ff" />
      </p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4>📦 Containerized Cloud Delivery</h4>
      <p>
        <sub><b>Docker</b> ile izole edilmiş mikroservis paketlemesi. Geliştirme ortamından üretim (production) sunucularına sıfır kesintiyle (zero-downtime) taşınabilen, yatayda ölçeklenmeye hazır standartlaştırılmış konteyner altyapısı.</sub>
      </p>
